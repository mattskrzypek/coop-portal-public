# Project guidance

Static household portal for coop.fatpigeon.ca.

- Live pages and assets: `index.html`, `apps.html`, `admin.html`, `flock.html`, `stats.html`, `watch.html`, `coop.css`, `coop.js`, `new-tab-links.js`, and `fonts/`.
- Live dated folders: `redesign-chat-media-20261020/`, `redesign-reference-20261020/`, and `nest-layout-20261020/`. Pages load code from these folders; do not rename them.
- Superseded folders: `redesign-20261020/`, `redesign-crumbs-20261020/`, and `crumbs-preview/`.
- `stats/` contains runtime data and is git-ignored. Never overwrite it on deploy.
